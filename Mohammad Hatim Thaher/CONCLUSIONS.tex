\section{Conclusion}
This project demonstrates that physiological signals can be used to generate secure, synchronized cryptographic keys in WBANs. By using local biometric data (ECG inter-pulse intervals) and a Bloom filter for reconciliation, sensors $S$ and $R$ derived an identical 160-bit key and confirmed it with matching HMAC tags, without the key ever being transmitted. The protocol fits the power constraints of IEEE 802.15.6: it replaces over-the-air key exchange with about 100 bytes of messages and inexpensive hash operations, which defeats passive eavesdropping and, through nonce-bound HMACs, prevents tampering, replay and MitM attacks from an attacker away from the body. Our validation also found and fixed a Bloom filter defect, bringing its false-positive rate from 49.5\% down to the 0.096\% design target. Future work includes testing with separate, noisy sensors, increasing feature entropy, moving to SHA-256, and measuring energy on real hardware.
